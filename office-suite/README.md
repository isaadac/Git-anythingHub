# Isadek Office

A free office suite for **Windows, macOS and Linux**, **Android and iOS**, and any modern browser. It has four apps; three of them work with Microsoft Office file formats:

| App | Like | Opens | Saves |
|---|---|---|---|
| **Isadek Write** | Word | `.docx`, `.html`, `.md`, `.txt` | `.docx`, `.html`, `.md`, `.txt`, PDF |
| **Isadek Sheets** | Excel | `.xlsx`, `.xls`, `.ods`, `.csv`, `.tsv` | `.xlsx`, `.xls`, `.ods`, `.csv`, PDF |
| **Isadek Slides** | PowerPoint | `.pptx`, `.aslides` | `.pptx`, `.aslides`, PDF |
| **Isadek Notes** | OneNote | `.anote` | saved as you type; `.anote`, Markdown, web page, or into Write |

## Features

**Write**: real pages like Word's Print Layout (text moves to the next page at the page edge; printing and PDF match the screen), headers and footers on every page with page numbers ("Page 1 of 3"), a different first page, **Track Changes** (accept/reject, All Markup / No Markup / Original) and **comments** with a comments pane, both saved as real Word revisions and comments in `.docx`, **footnotes and endnotes** (footnotes at the bottom of their page), **citations** in APA, MLA or Chicago style with a source manager and an automatic **bibliography**, all saved as real Word footnotes, endnotes and citation fields, **templates** (resume, cover letter, business letter, report, memo, meeting minutes, MLA essay, newsletter, invoice) from Home or File → New, **mail merge** from a CSV or spreadsheet (insert fields, preview each recipient, Finish & Merge into one document; fields are saved as Word MERGEFIELDs), ribbon UI, fonts and sizes, bold/italic/underline/strikethrough, sub/superscript, text and highlight colours, styles (Title, Headings, Quote, Code) you can **modify** (font, size, colour, bold/italic, spacing — applied everywhere and saved as Word's own styles), **section breaks** that start a new section in portrait or landscape with its own columns (real Word sections), **pictures text wraps around** (square left or right, top and bottom; saved as anchored Word pictures), **equations** typed in a simple linear form such as `x = (-b \pm sqrt(b^2-4ac))/(2a)` and shown as real math (saved as Word equations, and Word's equations open as editable ones), **fields** for date, time, author, file name, page, number of pages and word count (F9 updates them; saved as Word fields), **Compare** an earlier version with the document (Review tab: differences open as tracked changes in a new window), bullets and numbering, alignment, line spacing, shading, format painter, tables (add/remove rows and columns), pictures, links, page breaks, text boxes, symbols, date and time, **table of contents** with page numbers and dot leaders (click an entry to jump to it; Update Table rebuilds it; saved as a real Word TOC field, and Word's own contents opens as a live one), **PDF export with clickable contents and bookmarks** for every heading, header and footer, comments, find and replace, word count, read aloud, page setup (margins, orientation, Letter/A4/Legal, columns, page colour), navigation pane, print/web/focus/dark views, zoom.

**Sheets**: **tables** (Insert → Table: header row with sort and filter buttons, banded rows, a total row, rows and columns typed beside the table join it, a formula typed in a column fills the column, and **structured references** like `Table1[Sales]`, `[@Sales]` and `Table1[#All]`; saved as real Excel tables), **slicers** (buttons that filter a table column), **named ranges** (type a name in the Name Box, or Formulas → Name Manager; names of ranges, constants and formulas work in formulas and are saved as Excel defined names), **Goal Seek** and **Solver** (Data → What-If Analysis: maximise, minimise or hit a value by changing cells, with ≤, ≥, = and integer constraints), **sparklines** (line, column and win/loss charts inside cells; saved as Excel sparklines), **scripts** (Automate → Scripts: JavaScript with a workbook API like Office Scripts — `workbook.getActiveWorksheet().getRange("A1").setValue(…)` — run in an isolated worker with no network access; scripts that came with a file run only after you confirm), **data from the web** (Data → From Web: a CSV or JSON file or a table on a web page, into a new sheet or at the selection; Refresh All gets it again), **real Excel formatting** (fonts, sizes, bold/italic/underline, text and fill colours, borders, alignment, wrapping, number formats and locked cells are saved as Excel styles, and read from Excel files including theme colours; frozen panes too), a grid that grows as you scroll, **notes** on cells (red corner, hover, Show All, Shift+F2) and **protected sheets** (lock/unlock cells, optional password, allowed actions; Excel's protection and notes both ways), **charts** (column, bar, line, area, pie, doughnut, scatter and combo; saved as real Excel charts that Excel, LibreOffice and Google Sheets can edit, and Excel charts open as Isadek charts), **fill handle** (drag in any direction to continue numbers, dates, "Item 1"-style text, day and month names, or copy with Ctrl; double-click to fill down beside data; Fill → Series for linear, growth and date series), **PivotTables** (rows, columns, values with Sum/Count/Average/Max/Min, report filters, subtotals and grand totals, a PivotTable Fields pane and Refresh All; other apps see the summary values), **data validation** (lists with in-cell dropdowns, including lists from a range or another sheet; whole/decimal numbers, dates, times, text length and custom formulas; input messages; Stop/Warning/Information alerts; Circle Invalid Data; read from and saved as Excel validation), **conditional formatting** (highlight rules, text and duplicates, top/bottom and above/below average, formula rules, data bars, colour scales and icon sets, with a rules manager; saved as real Excel conditional formats and read from Excel files), multiple sheets (add, rename, duplicate, reorder, delete), a formula bar with function autocomplete, **270+ Excel functions** including **dynamic arrays** that spill like Excel 365 (FILTER, SORT, SORTBY, UNIQUE, SEQUENCE, XMATCH, TEXTSPLIT, VSTACK/HSTACK, TAKE/DROP, LET, A1# spill references, array maths and #SPILL!), INDIRECT/OFFSET, statistics (CORREL, PERCENTILE, NORM.DIST…), finance (IRR, XIRR, RATE, NPER, IPMT/PPMT, DDB…), and newer functions saved with the names Excel expects (SUM, AVERAGE, IF/IFS/IFERROR, SUMIF(S)/COUNTIF(S)/AVERAGEIF(S), VLOOKUP/HLOOKUP/XLOOKUP/INDEX/MATCH, text, date, statistics, PMT/FV/PV/NPV, …), cross-sheet references, relative and absolute references that adjust on copy, fill and insert/delete, circular-reference detection, number formats (currency, percent, dates, …), fonts, colours, borders, alignment, wrap, merge and centre, AutoSum, fill down/right, sort, filter, remove duplicates, text to columns, column and line/pie/bar charts, freeze panes, a status-bar sum/average/count, and Excel keyboard shortcuts.

**Slides**: **Morph** (duplicate a slide, move or resize things, and the objects glide between the two slides; saved as PowerPoint's Morph transition with matching object names), **Designer** (Design → Design Ideas: other layouts for the slide's title, text and pictures, one click to apply), **SmartArt** (list, process, cycle, hierarchy and pyramid diagrams from an outline; double-click to change the text or the kind), **Record** (Slide Show → Record: narration from the microphone and the time spent on each slide, saved as audio that plays by itself and as slide timings), **handouts** (1, 2, 3 with lines for notes, 4, 6 or 9 slides per page, or notes pages; print or PDF), **rotate, group and connect** (rotation handle with 15° snapping, rotate 90° and flip; Shift+click multi-select, Group/Ungroup with scaling; straight and elbow arrow connectors that stay attached when shapes move; saved as real PowerPoint connectors, and PowerPoint groups and connectors open as such), **video and audio** (MP4/WebM/MOV and MP3/WAV/M4A/OGG; poster frame, start automatically or on click, loop, hide the audio icon; embedded in .pptx and read from PowerPoint files), **Slide Master view** (master shapes and background on every slide, editable built-in layouts and custom layouts with placeholders, Reset slide, Header & Footer with slide numbers and date, hide background graphics per slide), much better PowerPoint import (placeholders inherit their position and text size from layouts and the master, group shapes keep their scaling, the deck's masters, layouts, backgrounds, theme colours and fonts come across), **Presenter View** (current slide, next slide or build, notes with zoom, timer and clock on your screen; the slides full screen on the second display, or in a second window), **animations** (entrance, emphasis and exit effects with direction, On Click / With / After Previous, duration, delay and order; builds play in the slide show and are saved as PowerPoint animations), **transitions** (fade, push, wipe, split, cover, uncover, zoom with duration and auto-advance, saved in .pptx), slide layouts, 6 themes, text boxes, 8 shape types, pictures, tables, drag/resize with snap guides, ordering and alignment, backgrounds (colour or picture), speaker notes, transitions, drag-to-reorder thumbnails, and a full-screen slide show.

**Notes**: notebooks with coloured sections and pages (and subpages), saved automatically as you type — no Save button. **Sync** (⇅ Sync): keep a notebook in Google Drive, OneDrive, Dropbox or a WebDAV server and it stays the same on every device — each device merges page by page (the newer page wins, deleted pages stay deleted), when it opens, as you work and every two minutes. **Page templates** (meeting notes, to-do list, Cornell lecture notes, daily journal, weekly planner, project overview, decision log), **file attachments** (any file up to 25 MB kept in the notebook; click to save a copy) and **audio notes** (record from the microphone into the page; click to play). Rich text with headings, lists, tables, pictures and links; **tags** — To Do checkboxes you can tick (Ctrl+1), Important (Ctrl+2), Question (Ctrl+3) and Idea (Ctrl+4) — with a to-do count in the status bar; **drawing** with pens, a highlighter and an eraser right on the page; **search** across every page of a notebook (Ctrl+E) that jumps to the match; rule lines and full-page view. Export a page as Markdown (to-dos become task lists) or a web page, open it in Write, or move a whole notebook as an `.anote` file. The Assistant can summarize a page or turn it into a to-do list. On the desktop each notebook is a file in the app's data folder (deleted notebooks go to a trash folder); in the browser they live in the browser's storage.

All apps have undo/redo, unsaved-changes prompts, recent files, print and PDF export, plus:

- **Cloud storage and sharing**: connect **Google Drive, OneDrive, Dropbox** or a **WebDAV** server (Nextcloud, ownCloud) on Home, then File → Open from Cloud / Save to Cloud. Ctrl+S and AutoSave write straight back to the cloud file, and **Share** (title bar) makes a view or edit link or invites people by email. Google Docs, Sheets and Slides files open as their Office equivalents; saving creates an Office copy beside them. Sign-in uses OAuth with PKCE in your normal browser (desktop) or a pop-up (web); tokens are kept encrypted with the OS keychain on the desktop (in the web version, in the browser's local storage). Each service needs an app registration. A copy built with the publisher's registrations connects with no setup; otherwise (or to use your organisation's own app) put its client ID in Home → Cloud → Settings, with the redirect address shown there — your own setting always wins over the built-in one.

  *Publishing with built-in registrations*: register an app with each service (Google Cloud console: an OAuth client of type *Desktop app* for the desktop builds and *Web application* for the web; Microsoft Entra: a public client with the redirects `http://localhost` and your web `…/src/renderer/oauth.html`; Dropbox App Console: PKCE, with the same redirects). Then set the repository variables `ISADEK_GOOGLE_CLIENT_ID`, `ISADEK_MICROSOFT_CLIENT_ID` (and optionally `ISADEK_MICROSOFT_TENANT`), `ISADEK_DROPBOX_APP_KEY` and the secret `ISADEK_GOOGLE_CLIENT_SECRET`; CI writes them into `src/renderer/cloud-apps.json` for every installer and phone app (locally: `node scripts/cloud-apps.js`). The web server reads the same variables from its environment. Google and Microsoft verify apps that ask for access to files before strangers may use them; until then only test users you list can sign in.
- **Phones and tablets**: Android and iOS apps from the same pages (Capacitor, in `mobile/`). Documents save to *Documents › Isadek Office* on the device, **Share** sends a copy with any app, Isadek Office appears under *Open with* for Word, Excel, PowerPoint, CSV, Markdown and text files, and the Android back button closes dialogs and panes, then returns Home. The layout fits phone screens (Write reflows text to the width, slide thumbnails shrink, panes go full screen), and objects, handles and charts can be dragged with a finger. **Print** and **Export PDF** work in the apps through their own plugin (`mobile/native`): the system print dialog (on Android, choose *Save as PDF*), and on iOS a paginated PDF saved to Documents and offered to share. The app icon and splash screen (light and dark) are made from `build/icon.png` when the native project is set up. Every CI run builds an Android APK (artifact *isadek-office-android*) and an iOS Simulator build (artifact *isadek-office-ios-simulator*). Build them yourself with `cd mobile && npm install && npm run apk` (Android SDK, Java 21), or `npm run ios` and open `ios/App` in Xcode. Installing on an iPhone or publishing to the App Store needs your Apple Developer account and signing certificate; set them in Xcode under *Signing & Capabilities*.
- **Dark mode**: File → **Office Theme** in any app (or 🎨 Theme on Home) chooses *Use system setting*, *Light* or *Dark*. Every open window switches at once and the choice is remembered; on the desktop, native menus and dialogs follow. As in Office, documents keep their own colours: Write's page stays paper-white (View → Dark page darkens it too), slides and charts look as they will when shown; the Sheets grid goes dark. Both themes pass axe-core's contrast checks.
- **Accessibility**: **Review → Check Accessibility** in every app lists errors, warnings and tips with one-click fixes, like Office's checker — Write: pictures without alt text, tables without a header row, skipped or empty headings, low-contrast text, unclear link text; Sheets: charts without titles, merged cells, low-contrast cells, default sheet names; Slides: slides without titles, duplicate titles, pictures and media without alt text, low-contrast text, overcrowded slides. **Alt Text** for pictures (Write) and pictures, video and shapes (Slides), or *mark as decorative*; it is saved in `.docx` and `.pptx` and read from PowerPoint files. Keyboard: arrow keys move through the ribbon tabs (Down enters the ribbon), **F6** moves between the title bar, ribbon, document, panes and status bar, Tab goes through the objects on a slide, and dialogs keep focus inside and hand it back when they close. Screen readers hear the current cell (value and formula) in Sheets and the selected object in Slides, and every control has a name; the pages pass axe-core with no violations. Respects *reduce motion* and Windows high-contrast (forced colours).
- **Spelling, grammar and languages**: red underlines as you type, with suggestions and *Add to Dictionary* on right-click (desktop). **Review → Spelling & Grammar** (F7) opens the Editor pane in Write, Sheets (text cells) and Slides (text boxes and speaker notes): it walks through misspellings and grammar slips — repeated words, extra spaces, spacing around punctuation, sentence capitals, "a"/"an", "i", could of, then/than, very long sentences — with Change, Change All, Ignore Once, Ignore All and Add to Dictionary. **Review → Language** (or the language in Write's status bar) sets the proofing language of a document from 50+ languages; Write saves it with the document. English grammar rules apply to English text; the others to every language.
- **Assistant (Claude)**: **✨ Assistant** in the title bar opens a pane to ask Claude about the open document, with one-click actions. Write: summarize, improve writing, fix spelling and grammar, shorten, make more formal, continue writing, with *Replace selection* and *Insert* (Markdown replies become headings, lists and tables). Sheets: write or explain a formula, analyze the selection, find mistakes; *Put in sheet* writes a formula into the active cell or pastes a table. Slides: draft slides from a topic, speaker notes, tighten a text box; *Add as slides* turns an outline into slides with bullets and notes. In the desktop app it uses your own Anthropic API key (⚙ in the pane), kept encrypted and never given to the pages; choose Claude Opus 5.5, Sonnet 5.5 or Haiku 5.5. In a browser (and the phone apps) it goes through an Isadek Office web server that holds the key — see *Hosting the web version* below.
- **Live editing**: click **Live** in the title bar to edit a document together in real time. Start a session on this computer (people on the same network join with the link) or on your own server (`npm run live-server`, or `node src/main/collab-server.js --port 8787` behind any TLS proxy for `wss://`), then send the invite link. The web server (`npm run web-server`) also hosts live sessions on its own port. Everyone sees the others' changes as they type, their cursors and selections with their names, and who is connected; edits made while the connection drops are sent when it comes back, and Undo takes back only your own changes. Write syncs paragraph by paragraph, Sheets cell by cell, Slides shape by shape; when two people change the same paragraph, cell or shape at the same moment, the later change wins.
- **AutoSave**: the switch in the title bar saves to the file a few seconds after each change (desktop app or cloud documents; `.docx`/`.html`, `.xlsx`/`.ods`, `.pptx`/`.aslides`).
- **Crash recovery**: unsaved changes are kept as a draft every 30 seconds. If the app crashes or the computer loses power, Home lists the recovered documents next time. If a single window crashes, it offers to reopen with your changes.

## Install

Download the installer for your system from the repository's **Releases** page (or from the latest **Actions → Isadek Office** run's artifacts):

- **Windows**: `Isadek-Office-Setup-x.y.z-x64.exe` (installer; `-arm64` for ARM PCs) or `Isadek-Office-x.y.z-portable.exe` (no install needed)
- **macOS**: `Isadek-Office-x.y.z-universal.dmg` (Intel and Apple Silicon)
- **Linux**: `Isadek-Office-x.y.z-x86_64.AppImage` (any distro: `chmod +x` and run) or `isadek-office_x.y.z_amd64.deb` (Debian/Ubuntu)

Builds are code-signed once signing certificates are added to the repository (see [SIGNING.md](SIGNING.md)). Until then, Windows SmartScreen may warn you ("More info → Run anyway"), and on macOS you right-click the app and choose **Open** the first time.

**Phones, tablets and Chromebooks**: serve the `office-suite` folder from any static web host and open `src/renderer/index.html`. The same apps run in the browser. Saving downloads the file.

### Updates

Installed copies (Windows installer, macOS app, Linux AppImage and `.deb`) check the repository's latest GitHub Release every 6 hours, download new versions in the background and offer to restart. Use **Help → Check for Updates…** to check now, or untick **Help → Update Automatically** to turn this off. The portable `.exe` doesn't update itself. On macOS, updates need a signed build (see [SIGNING.md](SIGNING.md)).

To ship an update, raise `version` in `package.json` and push a tag such as `office-v1.0.1`.

## Develop

```bash
cd office-suite
npm install
npm start          # run the desktop app
npm test           # formula engine tests
npm run dist       # build installers for the current OS into dist/
npm run dist:win   # or :mac / :linux
```

To publish a release with installers for all three systems, push a tag such as `office-v1.0.0`. `.github/workflows/office-suite.yml` builds on Windows, macOS and Linux runners and attaches the files to a GitHub Release.

## How it's built

- `src/main/`: Electron main process (windows, native menus, file dialogs, file associations, recent files) and a minimal, context-isolated preload bridge.
- `src/renderer/`: the three apps as plain HTML/CSS/JS with no build step. `js/platform.js` hides the desktop/web difference.
- `src/renderer/js/formula.js`: the spreadsheet engine (tokenizer, parser, evaluator, reference rewriting), with tests in `test/`.
- File formats: [docx](https://github.com/dolanmiu/docx) and [mammoth](https://github.com/mwilliamson/mammoth.js) for Word, [SheetJS](https://sheetjs.com) for spreadsheets, [PptxGenJS](https://github.com/gitbrent/PptxGenJS) and [JSZip](https://stuk.github.io/jszip/) for PowerPoint.

## Security and large files

- Documents are treated as untrusted. Opened and pasted content is sanitized (no scripts, frames, forms or remote content), and every page runs under a strict Content Security Policy.
- The renderer runs sandboxed with no Node.js access. It can only read or overwrite files the user picked in a dialog, opened from the OS or reopened from the recent list.
- Spreadsheet files are parsed in a throwaway Web Worker with a time limit, so a malicious file can't affect the app or freeze it. This contains the known SheetJS advisories (CVE-2023-30533 and CVE-2024-22363) in the npm build of `xlsx` 0.18.5. Upgrading to SheetJS 0.20.3 (`npm i https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz`) removes them entirely.
- Sheets renders only the visible part of the grid, so workbooks with hundreds of thousands of rows open and scroll smoothly. Formula chains of any length (such as running totals down 100,000 rows) calculate without hitting the JavaScript stack limit.

## Known limitations

Isadek Office covers the everyday features of Word, Excel and PowerPoint, not all of them. Some things don't survive a round trip through Office files:

- **Write**: a single table or block taller than a page isn't split across pages, and multi-column layouts flow without page breaks. Pages after a landscape section break are shown and printed at the document's page size (the orientation is kept in .docx); headers and footers are the same in every section, and pictures positioned at exact places on the page are opened as wrapped left or right.
- **Sheets**: other apps see a pivot table's values, not a live pivot. VBA macros are not supported (scripts are JavaScript). Slicers are kept by Isadek Office but not saved as Excel slicer objects (the table's filter is saved). Solver uses a general-purpose search, so very large or badly scaled models may get a close rather than an exact answer. In the web version, From Web works only with sites that allow it (the desktop app reads any site). Diagonal borders, gradient fills and border styles other than thin are simplified when an Excel file is opened.
- **Slides**: SmartArt, 3D models, Morph and other effects Isadek doesn't have are dropped when a `.pptx` opens. Save as `.aslides` to keep a presentation exactly as it is.
- **Live editing**: in Write, comments, footnotes and citation sources aren't shared live yet, and Undo during a session uses the browser's own history, which can also take back other people's edits to the same paragraph. The relay server keeps sessions in memory only; anyone with the link can join, so share it only with people you trust, and use `wss://` across the internet.
- **Cloud**: the web version can only reach WebDAV servers that allow cross-origin requests (Nextcloud needs a CORS app); the desktop app has no such limit. Files over 250 MB can't be saved to OneDrive.

## Hosting the web version

`npm run web-server` serves the web app, the Assistant and live editing on one port (default 8080):

```sh
npm ci --omit=dev
ANTHROPIC_API_KEY=sk-ant-… ASSISTANT_CODES=team-code-1,team-code-2 npm run web-server -- --port 8080
```

Open `http://your-server:8080/`. The API key stays on the server: pages send their questions to `/api/assistant` and the reply streams back. People type one of the **access codes** in the Assistant settings (⚙), so strangers can't spend your credit; set `ASSISTANT_OPEN=1` instead to let anyone who can reach the server use it. Questions are limited per code to `ASSISTANT_PER_MINUTE` (default 10). To use the server's Assistant from pages hosted elsewhere (or from the phone apps), list those sites in `ASSISTANT_ORIGINS` (for the apps: `https://localhost,capacitor://localhost`) and enter the server's address in the Assistant settings. Put it behind a TLS proxy (Caddy, nginx) for `https://` and `wss://`. It serves only the app's pages and the library files they load.
