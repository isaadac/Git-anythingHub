Isadek Office Help

Getting started

Isadek Office is four apps that work like the Office apps you know: Write for documents, Sheets for spreadsheets, Slides for presentations and Notes for notebooks. Start from Home (File → Home), which lists templates, recent files, files on your cloud accounts and anything recovered after a crash.

Each app has a ribbon of tabs (Home, Insert, …) and a File tab for opening, saving, printing, exporting, sharing and settings. Not sure where a command is? Press Alt+Q and type what you want to do.

Saving, AutoSave and versions

Ctrl+S saves; File → Save As picks a new name or format. While you work, Isadek Office keeps a draft of every unsaved document; if the app or the computer stops unexpectedly, Home offers the drafts the next time it starts.

Every save also keeps a version of the document — at most one every ten minutes, the latest thirty. File → Version History lists them: open one as a copy, or restore it (you can restore the newest again if you change your mind).

Passwords. File → Protect with Password encrypts a .docx, .xlsx or .pptx when you save it (AES-256, as Office does), so it opens only with the password — in Isadek Office, Word, Excel and PowerPoint. Protected files from Office open here too. A forgotten password can’t be recovered.

Write

Styles and headings (Home), tables, pictures that wrap around text, page and section breaks, headers and footers with page numbers, footnotes and endnotes, citations and a bibliography, a table of contents, equations (Insert → Equation, in a linear syntax such as x = (-b ± sqrt(b^2-4ac))/(2a)) and fields that update themselves (F9).

References → Sources is a reference manager: search the sources in your document and the ones you used before, add one by DOI, paste or import BibTeX and RIS from Zotero, Mendeley, EndNote or Google Scholar, cite with one click and export BibTeX. Styles: APA, MLA, Chicago, Harvard and IEEE.

Review has spelling and grammar, track changes, comments, Compare (side by side, or as tracked changes) and Read Aloud. Mailings makes letters from a list of recipients. View → Navigation Pane jumps between headings.

Sheets

Formulas start with = and use the functions Excel has (Formulas → Insert Function lists them), including dynamic arrays. Drag the fill handle to copy formulas or continue a series. Insert → Table turns a range into a table with filters, a total row and names like Table1[Sales] in formulas.

Also: charts and sparklines, PivotTables, conditional formatting, data validation and drop-down lists, cell comments, protected sheets, named ranges (Name Manager), Goal Seek and Solver (Data → What-If Analysis), data from the web, and scripts (Automate).

Data → Clean & Transform tidies a range step by step (trim, change case, split and merge columns, fill down, filter, remove duplicates, group, unpivot…) with a live preview; the result goes to a new sheet, and Refresh All runs the steps again on new data. Charts include waterfall, funnel and map (countries shaded by value).

Insert → Form builds a form people answer from a link, on any device: choose the questions (short or long answers, numbers, email, dates, multiple choice, checkboxes, drop-downs, ratings), then Publish and copy the link. Answers arrive as rows in a Form Responses sheet (Get Responses, or by themselves every minute while the workbook is open), with a summary in the Forms pane. In the desktop app, “This computer” collects answers from people on the same network while Isadek Office is open. Fill In types a response here; Stop Accepting closes the form. Whoever has the workbook can collect its forms’ answers.

=PY("code", value…) runs Python in a cell: xl("A1:B10") reads cells as a list of rows, args holds the values after the code, and a list of lists spills into the cells below. It runs on your device with no network or file access; Python in a workbook from someone else runs only after you choose Run Python.

Slides

Pick a layout for each new slide, a theme on Design, and transitions (including Morph) and animations for anything on a slide. Designer suggests layouts; SmartArt builds diagrams from a list. F5 starts the show; Presenter View shows your notes, the next slide and a timer. Record Slide Show adds narration and timings. Print handouts with 1 to 9 slides per page.

Draw lets you write and sketch on slides with a pen (pressure shapes the line), your finger or the mouse; Write → Draw → Drawing does the same in documents. Insert → Cameo puts your camera, live, in a slide while you present. Slide Show → Live Captions shows what you say at the foot of the slides (C during the show), and Rehearse with Coach listens to a practice run and reports your pace, filler words, slides you read aloud and the time on each slide.

Notes

Notebooks hold sections, sections hold pages. Pages take text anywhere, to-do tags, tables, pictures, files, audio recordings and drawing with a pen or highlighter. Notebooks save as you type; Sync keeps a notebook in your cloud storage so every device has the same pages.

PDF

Isadek PDF opens PDF files to read, search (Ctrl+F) and print. Annotate highlights text (select it, or drag over an area), draws with a pen or finger, adds text and comments; the Eraser removes them. Fill & Sign fills in the PDF's own form fields right on the page, adds today's date and a signature you draw once and reuse.

Pages shows every page down the side: drag to reorder, rotate, delete, insert another PDF, extract the selected pages as a new PDF, or split the file. Edit in Write turns the text into an editable document. Saving writes a standard PDF that any reader opens; comments stay real PDF comments. PDFs protected with a password can be read but not saved.

Cloud storage, sharing and live editing

Add a place on Home (or File → Open from Cloud) connects Google Drive, OneDrive, Dropbox or a WebDAV server (Nextcloud, ownCloud). Files open from and save back to the account directly; Isadek Office has no server in between. Share sends a link, or starts live editing so several people can work on a document at once (each person's Undo undoes only their own changes).

Offline. Saving a cloud document without a connection keeps it on this device (the title bar says “Saved on this device”) and it goes up by itself when the connection is back. If someone changed the file in the meantime, nothing of theirs is overwritten: your version is saved next to it as a “conflicted copy”. Cloud files you have opened recently open offline from Home, and the web version opens without a connection once it has been used.

Assistant

✨ Assistant (Home tab) drafts, rewrites, summarises and explains, using Anthropic's Claude. It needs an Anthropic API key (⚙ in the Assistant pane) or, on the web, a server that provides one. Only what you send it — your request and the text or cells you chose to include — leaves your computer.

Theme and language

File → Office Theme chooses light, dark or the system setting. File → Language shows the interface in English, Español, Français, Deutsch or Português; your documents are never changed. Spelling languages are set in Review → Language.

Troubleshooting

A window stopped working

Choose Reopen: the window comes back with your unsaved changes. Drafts of other documents are on Home.

A file won't open, or looks different

Isadek Office reads and writes the Office formats, but a few features of other apps (macros, embedded objects from other programs) aren't supported; they are kept where possible and otherwise left out. If you can share the file, please report it.

Crash reports

When something goes wrong, a report is kept on your computer (Help → Show Crash Reports). It describes the error, not your documents. Turn on Help → Send Crash Reports to send these reports to the Isadek Office developers so they can fix the problem.

Updates

The desktop app checks for updates and installs them when you quit (Help → Update Automatically turns this off; Help → Check for Updates checks now).

Privacy

Isadek Office privacy policy · last updated 28 October 2026

Isadek Office is made to keep your work yours. It has no accounts, no advertising and no analytics.

Your documents

Documents, notebooks, drafts and versions are stored on your device (in the desktop app's data folder, or in your browser for the web version). They are not sent to the developers of Isadek Office.

When something leaves your device

  • Cloud storage. If you connect Google Drive, OneDrive, Dropbox or a WebDAV server, files you open or save there go directly between your device and that service, under its own privacy policy. The sign-in token stays on your device (encrypted where the system allows).
  • Live editing. When you start or join a live session, changes to that document go through the live-editing server the session uses, to the other people in it. The server keeps the session in memory only, and forgets it an hour after everyone has left.
  • Assistant. When you use ✨ Assistant, your request and the content you include are sent to Anthropic (directly with your own API key, or through the web server you use) to produce an answer. Anthropic's privacy policy applies to that data.
  • Data from the web. Sheets → From Web downloads the address you enter.
  • Speech model. Choosing speech recognition on this device downloads the model from Hugging Face (huggingface.co) once.
  • Looking up a DOI. Write → Sources → DOI asks Crossref (api.crossref.org) for that DOI's details.
  • Updates. The desktop app asks the release server whether a newer version exists. That request includes the app's version and your operating system, as any download does.
  • Crash reports are sent only if you turn them on (Help → Send Crash Reports; off by default). A report holds the error message and where in the program it happened, the app and system versions, and for a native crash a memory snapshot of the program that stopped. File paths are shortened so they don't include your user name. Reports are used only to fix problems and are deleted after 90 days.

Microphone and camera

The microphone is used only while you record narration in Slides or an audio note in Notes (the recording is stored in your file), or while you dictate, show live captions or rehearse with Coach. Dictation, captions and Coach can recognize speech on this device (File → Speech): the speech model (OpenAI's Whisper) is downloaded from Hugging Face once, when you choose it, and after that nothing you say leaves your computer, even without a connection. Or they can use your browser's own speech recognition, which sends the audio to its provider (Google for Chrome, Apple for Safari, Microsoft for Edge); nothing said is kept. The camera is used only to show you in a Cameo while you present in Slides; nothing is recorded or sent. Your screen is never used.

Children

Isadek Office does not knowingly collect any personal information, from children or anyone else.

Changes and contact

Changes to this policy are published with new versions of the app. Questions: open an issue at github.com/isaadac/Git-anythingHub.
